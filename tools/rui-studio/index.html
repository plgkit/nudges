Decision reminders (ELI5)
  • Emphasize by de-emphasizing — make the hero loud; quiet nav and chrome.
  • Fewer borders — separate with background color or whitespace first.
  • Limit font sizes — pick from your scale; don’t invent a new size per line.
  • Labels last — layout and hierarchy should explain the UI before extra text.
  • One primary action per card — one filled button; dismiss stays subtle.
  • Don’t gray-out important text — muted is for hints, not body copy.
  • Start from a real screen — preview should look like a product, not a spec.
