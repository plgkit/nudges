# Python examples

The examples in `spec/examples/` default to TypeScript. If your project uses Python, use the files in this `python/` folder instead of their TypeScript counterparts in the root. For example, use `audiences.py` instead of `../audiences.ts`.

The message YAML files in `../messages/` are shared by every language.

In your own app, the audience file lives at `plgkit/audiences.py`.
